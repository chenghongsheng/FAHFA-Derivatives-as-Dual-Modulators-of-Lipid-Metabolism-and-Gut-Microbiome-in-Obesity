# FAHFA Derivatives as Dual Modulators of Lipid Metabolism and Gut Microbiome in Obesity

This repository contains the R scripts for the RNA-seq analysis and 16S rRNA profile analysis. The study aims to explore the mechanism of selected FAHFAs in obesity and metabolic benefits.

## Contents of the Repository

- RNAseq: This folder includes the count data, metadata and R script detailing the pipeline used transcriptome analysis of the intestinal epithelial scrapings.
- 16S: This folder includes the count data and Rscript for analysis of the 16S rRNA profiles.

## Overview

In a diet-induced obesity mouse model, oral administration of FAHFA derivatives reduced weight gain, improved glucose tolerance, and attenuated ectopic lipid deposition, rivaling the efficacy of semaglutide. Mechanistically, 12-TAASA and 12-HDTZSA remodeled the gut microbiome by enriching SCFA producing taxa. 12-TAASA also suppressed intestinal lipid absorption via transcriptomic regulation of key genes. These findings position synthetic FAHFAs as dual-action therapeutics, targeting both host lipid metabolism and gut microbiota dysbiosis, offering a promising strategy for obesity and metabolic disorders.
